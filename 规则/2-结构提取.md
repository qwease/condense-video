# 结构提取规则

## 章节识别方法

### 1. 显式标记识别

**章节词**：
```
- "第一章"、"第二章"、...
- "第一节"、"第二节"、...
- "接下来我们讲"、"下面来看"
- "现在开始"、"首先"、"然后"
- "这个问题讲完了，下面"
```

**处理逻辑**：
```javascript
const chapterKeywords = [
  /第[一二三四五六七八九十\d]+[章节]/,
  /接下来我们/,
  /下面我们[来讲]/,
  /现在开始/,
];

if (chapterKeywords.some(k => sentence.text.match(k))) {
  markAsChapterStart(sentence);
}
```

### 2. 主题聚类识别

**方法**：对连续的 `core` 句子提取关键词，当关键词主题发生变化时，标记新章节。

**示例**：
```
句子 1-20: 包含"传递函数"、"拉氏变换" → 章节1：传递函数基础
句子 21-40: 包含"波特图"、"频率响应" → 章节2：频域分析
句子 41-60: 包含"稳态误差"、"增益" → 章节3：稳态分析
```

**关键词提取**：
```
1. 从 core 句子中提取名词短语
2. 合并相似关键词
3. 统计每个主题的连续分布
4. 主题切换点即为章节边界
```

### 3. 长停顿识别

**规则**：≥3秒的静音后的新内容，可能是新章节的开始。

```javascript
if (gap >= 3.0 && nextSentence.label === 'core') {
  candidateChapterBoundary = nextSentence.startIdx;
}
```

### 4. 内容类型切换

**规则**：从 `chat`/`interact` 切换到 `core`，可能是新章节。

```
[闲聊] → [核心知识] → 章节边界
[互动] → [核心知识] → 章节边界
```

## 章节合并规则

### 过短的章节

如果章节时长 < 30秒，考虑与相邻章节合并：

```
章节A: 20秒
章节B: 2分钟
→ 合并为一个章节
```

### 无核心内容的段落

如果一段内容全部是 `interact`/`chat`，不作为独立章节：

```
[互动5分钟] → 不标记为章节，标记为"课堂互动段落"
```

## 章节标题生成

基于章节内容的关键词，自动生成简洁的标题：

**模板**：
```
{主题} + {方面}
例：传递函数 + 基础 → "传递函数基础"
例：波特图 + 绘制方法 → "波特图绘制"
例：稳态误差 + 计算 → "稳态误差计算"
```

**关键词优先级**：
1. 出现频率最高的专业术语
2. 定义性语句中的概念
3. 公式/定理名称

## 手动调整

生成的大纲应支持用户手动调整：

```
1. 合并章节
2. 拆分章节
3. 修改标题
4. 调整边界
```

这些调整可以记录到用户偏好中，用于后续视频的自动优化。
