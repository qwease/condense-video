# 总结生成规则

## 课程总结模板

### 整体结构

```markdown
# [课程名称] - 内容精要

## 课程概述
[1-2句话概括课程主题和目标]

## 章节目录
1. [章节1标题]
2. [章节2标题]
3. ...

---

## 详细内容

### 第一章：[章节标题]
[时间范围：XX:XX - XX:XX]

#### 核心概念
- **概念1**：定义/解释
- **概念2**：定义/解释

#### 重要公式
- 公式1：`[公式]` - 说明
- 公式2：`[公式]` - 说明

#### 关键要点
- 要点1
- 要点2

---

### 第二章：[章节标题]
...

---

## 总结
[整体总结，核心要点回顾]
```

## 要点提取规则

### 核心概念提取

从 `core` 类型的句子中提取：

**识别模式**：
```
"XXX是XXX" → 概念定义
"XXX称为XXX" → 概念命名
"XXX等于XXX" → 公式关系
"XXX包括XXX" → 分类列举
```

**输出格式**：
```markdown
- **传递函数**：零初始条件下，输出与输入的拉氏变换之比
- **增益**：系统化成标准式后的比例系数 K
- **转角频率**：波特图中斜率发生变化的频率点
```

### 公式提取

从包含数学表达式的句子中提取：

**识别模式**：
```
包含 "s"、"t"、"ω"、"ζ" 等符号
包含 "等于"、"分之"、"平方"
包含数字和运算符
```

**输出格式**：
```markdown
- **一阶惯性环节**：`G(s) = 1/(Ts+1)`
- **二阶振荡环节**：`G(s) = ωn²/(s² + 2ζωns + ωn²)`
```

### 方法步骤提取

从包含步骤描述的句子中提取：

**识别模式**：
```
"首先...然后...最后"
"第一步...第二步"
"先...再"
```

**输出格式**：
```markdown
**波特图绘制步骤**：
1. 将传递函数化为标准形式
2. 确定增益 K 和各转角频率
3. 绘制低频段渐近线
4. 依次处理各转角频率后的斜率变化
```

## 章节摘要生成

### 摘要长度

- 每章节摘要：50-100字
- 整体总结：100-200字

### 摘要内容

必须包含：
1. 本章主题
2. 核心概念（2-3个）
3. 重要结论

**示例**：
```markdown
本章介绍控制系统的典型环节及其传递函数。重点掌握：
比例、积分、微分、惯性、振荡五种典型环节的标准形式，
以及如何将一般传递函数化为标准形式以确定增益和转角频率。
```

## 排除内容

以下内容不进入总结：
- 课堂互动（提问、回答）
- 闲聊跑题
- 过渡语句
- 重复表达

## Markdown 格式规范

### 标题层级
```
# 课程名称
## 章节
### 小节
#### 要点
```

### 强调标记
```
**加粗**：重要概念、关键词
`代码`：公式、符号
- 列表：要点、步骤
```

### 时间标注
```
[00:00] 开场
[00:32] 第一章开始
[05:40] 第二章开始
```

## 输出文件

### summary.md
完整的课程总结文档，包含所有章节的详细内容。

### key_points.md
精简版要点清单，仅包含：
- 核心概念列表
- 重要公式汇总
- 关键结论

**示例 key_points.md**：
```markdown
# 自动控制原理 - 核心要点

## 核心概念
- 传递函数
- 增益
- 转角频率
- 波特图

## 重要公式
- 一阶惯性：`1/(Ts+1)`
- 二阶振荡：`ωn²/(s²+2ζωns+ωn²)`

## 关键结论
1. 传递函数必须化为标准形式才能确定增益
2. 波特图低频段斜率由积分环节数量决定
3. 转角频率处斜率变化由环节类型决定
```
