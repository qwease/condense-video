# 内容分类规则

## 分类体系

### 1. 核心知识 (core) - 必留

**特征**：
- 定义概念
- 公式定理
- 重要结论
- 关键方法
- 核心原理

**判断标准**：
```
✓ 包含"定义是"、"公式是"、"定理是"
✓ 包含"等于"、"称为"、"记作"
✓ 数学表达式、公式
✓ 关键概念首次出现
✓ 步骤/流程的核心描述
```

**示例**：
```
"传递函数的定义是零初始条件下输出与输入的拉氏变换之比"
"二阶振荡环节的标准形式是 t方s平方加二倍zeta ts加1分之1"
"增益是指系统化成标准式后的k值"
```

### 2. 解释说明 (explain) - 可选

**特征**：
- 对核心内容的展开
- 举例说明
- 类比解释
- 补充细节

**判断标准**：
```
✓ 包含"比如说"、"举个例子"、"换句话说"
✓ 包含"意思是"、"也就是说"
✓ 对前文内容的进一步解释
✓ 具体案例分析
```

**示例**：
```
"比如说刚才这个式子，我们把omega等于1除以t代进去"
"换句话说，就是你先画成标准式"
```

### 3. 课堂互动 (interact) - 建议删

**特征**：
- 师生问答
- 点名提问
- 课堂讨论
- 反馈回应

**判断标准**：
```
✓ 包含人名（学生名）
✓ 包含"谁来说"、"你来回答"
✓ 包含"对不对"、"是不是"（期待回应）
✓ 包含"听懂了吗"、"有问题吗"
✓ 学生发言、回答问题
```

**示例**：
```
"李明你来说这是什么系统"
"对不对呀"
"你们听懂了吗"
"哈哈哈哈"（课堂笑声）
```

### 4. 闲聊/跑题 (chat) - 必删

**特征**：
- 与课程无关
- 跑题内容
- 个人闲聊
- 课堂管理

**判断标准**：
```
✓ 包含"作业"、"考试"（非知识点）
✓ 包含"上次课"、"下次课"（非当前内容）
✓ 包含"你们太好了"、"全都是a"
✓ 个人经历、轶事（非教学目的）
✓ 课堂纪律、考勤相关
```

**示例**：
```
"你们作业做的都太好了"
"有一年学生说刘老师不收作业"
"平时分你们卷面上能过得去就行"
"哈哈哈哈平时分"（闲聊引发的笑声）
```

### 5. 过渡语 (transition) - 可删

**特征**：
- 承上启下
- 话题转换
- 填充语句

**判断标准**：
```
✓ 纯过渡词："那么"、"接下来"、"下面"
✓ 重复强调："这个很重要"、"一定要记住"
✓ 口头禅式的填充
```

**示例**：
```
"那么接下来我们"
"所以说呢"
"这个呢就是说"
```

## 分类优先级

当一句话可能属于多个类别时，按以下优先级判断：

```
core > explain > interact > chat > transition
```

**示例**：
- "那么传递函数的定义是..." → core（包含核心知识，忽略"那么"）
- "比如说这个公式很重要" → explain（举例性质）
- "这个很重要你们要记住" → transition（无实质内容）

## 边界情况

### 混合内容

一句话包含多种内容时，按主体内容分类：

```
"这个公式很重要，你们考试肯定会考"
→ 主体是强调重要性（transition），考试提醒是附带的
→ 但如果前面是公式定义，则整句保留
```

### 模糊内容

无法明确判断时，保守处理：

```
原则：宁可保留，不要误删
- 不确定 → explain（可选保留）
- 疑似核心 → core（保留）
```
